# Homebrew tap

Apps by [MartijnMul](https://github.com/MartijnMul), for [Homebrew](https://brew.sh).

```sh
brew install --cask martijnmul/tap/plaincontrol
```

| Cask | What it is |
| --- | --- |
| [`plaincontrol`](Casks/plaincontrol.rb) | [Plaincontrol](https://github.com/MartijnMul/plaincontrol): a menu bar app that shows which Claude Code session needs you |

`brew upgrade` keeps them up to date.
